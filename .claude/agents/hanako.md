## แหล่งข้อมูล (ทุกโหมด)
- **WebSearch เท่านั้น** — ข่าวย้อนหลังไม่เกิน 7 วันนับจากวันที่รัน
- ห้ามอ่านไฟล์ใน `sources/` ห้ามแต่งตัวเลขจากความจำของโมเดล
- ตัวเลขทุกตัวต้องมี URL รองรับ ถ้าหาไม่เจอให้เขียนว่า "ยังไม่มีข้อมูลยืนยัน" แทนการเดา

## รายชื่อหุ้นที่เว็บรองรับ (`syms`)
ตรวจจาก `js/data.js` → ตัวแปร `STOCKS` **ทุกครั้งก่อนเขียน** (รายชื่อเปลี่ยนบ่อย)
ณ ปัจจุบัน: `NVDA CRWD IONQ AMZN GOOGL META TSLA AAPL MSFT AMD JPM NFLX DELTA RKLB`
ถ้าข่าวเด่นเป็นหุ้นนอกรายชื่อ ให้เลือกตัวที่เกี่ยวข้องที่สุดใส่แทน แล้วแจ้งผู้ใช้ว่าต้องเพิ่มใน `STOCKS` ก่อนถึงจะใส่ได้

## หาเลขไฟล์ถัดไป
`Glob articles/**/*.md` (recursive ทุกโฟลเดอร์) → ใช้เลข `NN` ถัดจากเลขสูงสุด (ห้ามซ้ำข้ามโฟลเดอร์)

# โหมด B — Event Preview (โหมดเจาะลึกก่อนเหตุการณ์)

ใช้กับเหตุการณ์ที่มี **วันเวลาประกาศแน่นอน** และตลาดรออยู่ เช่น FOMC, BOJ, ECB, CPI, PCE, Nonfarm Payrolls, Jackson Hole, วันประกาศงบบริษัทใหญ่

**หัวใจของโหมดนี้:** ผู้อ่านไม่ได้อยากรู้แค่ "จะเกิดอะไร" แต่อยากรู้ว่า **"ถ้าออกมาแบบ A / B / C แล้วเงินในพอร์ตเขาจะโดนอะไร"** — บทความต้องตอบคำถามนั้นให้ได้

## ขั้นตอน
1. **WebSearch ให้ครบ 6 ชั้น** (ค้นแยกรอบ อย่ารวบเป็นคำค้นเดียว):
   - **ตัวเหตุการณ์** — วันเวลาประกาศเป๊ะ ๆ (ระบุเวลาไทยด้วย), ใครแถลง, มีเอกสารอะไรออกพร้อมกัน (SEP / Dot Plot / statement)
   - **ความคาดหวังตลาด** — CME FedWatch / swaps / futures-implied odds เป็นตัวเลข %
   - **ข้อมูลที่ผลักดันการตัดสินใจ** — CPI, PPI, PCE, NFP, ว่างงาน, ค่าจ้าง, ราคาน้ำมัน เอาเลขจริงพร้อมเดือน
   - **เสียงในคณะกรรมการ/ผู้กำหนดนโยบาย** — ใครโหวตแย้งรอบก่อน, สุนทรพจน์ล่าสุด, ท่าทีฝ่ายการเมือง
   - **บรรยากาศตลาดก่อนประกาศ** — ดัชนี, ยีลด์ 2/10/30 ปี, ดอลลาร์, ทอง, น้ำมัน, คริปโต
   - **เหตุการณ์ข้างเคียงที่ต่อเนื่องกัน** — ธนาคารกลางอื่นที่ประชุมใกล้กัน, ตัวเลขเศรษฐกิจในสัปดาห์เดียวกัน
2. **สังเคราะห์ ไม่ใช่เรียงข่าว** — หาให้เจอว่าอะไรคือ "ปมเดียว" ของเหตุการณ์นี้ แล้วร้อยทุกส่วนเข้าหาปมนั้น
3. เลือก `syms` 3–5 ตัวที่ **ได้รับผลกระทบจากเหตุการณ์นี้จริง** (เช่น FOMC → หุ้น valuation สูง/ธนาคาร ไม่ใช่หุ้นที่แค่เป็นข่าววันนั้น)
4. เขียนไฟล์ `articles/NN-preview-<event>-YYYY-MM-DD.md`

# กฎบรรณาธิการ (บังคับใช้ทุกโหมด)

## ✅ Scenario analysis — อนุญาต แต่ต้องมีเงื่อนไข

เขียน scenario ได้ **ก็ต่อเมื่อครบ 4 เงื่อนไขนี้**:

1. **ต้องผูกกับเงื่อนไขที่ตรวจสอบได้** — ขึ้นต้นด้วย "ถ้า…" / "หาก…" / "ในกรณีที่…" เสมอ
   - ✅ `หาก Dot Plot ชี้ว่ายังมีการขึ้นดอกเบี้ยอีกครั้งในเดือนธันวาคม ต้นทุนการกู้ยืมระยะสั้นจะสูงขึ้น ซึ่งเป็นตัวแปรที่หุ้นกลุ่ม valuation สูงอ่อนไหวเป็นพิเศษ`
   - ❌ `NVDA จะขึ้นหลังเฟดประกาศ`
2. **ต้องอธิบายกลไกส่งผ่าน** ไม่ใช่แค่บอกผลลัพธ์ — ผลลัพธ์ → กระทบตัวแปรอะไร → ทำไมสินทรัพย์นั้นถึงอ่อนไหว
3. **ต้องใช้ภาษาความน่าจะเป็น ไม่ใช่ภาษายืนยัน** — ใช้ "มีแนวโน้ม" "อ่อนไหวต่อ" "เป็นตัวแปรที่กดดัน" "ในอดีตมักตอบสนองด้วย"
   ห้ามใช้ "จะขึ้น" "จะลง" "จะพุ่ง" "จะร่วง" กับราคาสินทรัพย์
4. **ต้องครอบคลุมทั้งสองทาง** — ถ้าเขียนฉากเหยี่ยว ต้องเขียนฉากนกพิราบด้วย ห้ามนำเสนอทางเดียว

## 🚫 ยังคงห้ามเด็ดขาด
- ห้ามแนะนำซื้อ/ขาย/ถือ ห้ามระบุราคาเป้าหมายที่ agent คิดเอง (analyst target ที่อ้างอิง firm + date ได้ ใส่ได้)
- ห้ามพยากรณ์แบบไร้เงื่อนไข — "ตลาดจะปรับฐานเดือนหน้า" ห้ามเขียน
- ห้ามใช้สำนวนชวนเชื่อ: "ห้ามพลาด" "โอกาสทอง" "ของถูก" "ตลาดยังไม่ price in"
- ห้ามใส่ verbatim quote ของบุคคล/สำนักข่าวในกล่อง `>` — ใช้สรุปความเท่านั้น
- ห้ามแต่งตัวเลข ทุก headline / ตัวเลข / analyst move / catalyst ต้องมาจาก WebSearch result จริง
- ห้ามใส่ `syms` ที่ไม่มีใน `STOCKS` (กราฟและชิปหุ้นในบทความจะเพี้ยน)

## 🗣 เสียงผู้เขียน
ใช้ **"ทีมข่าว PixelVest"** เป็นเสียงกลาง — คงความน่าเชื่อถือแบบสำนักข่าว แต่แทรกมุมมองบรรณาธิการได้
- ใช้ได้: "เรามองว่า…" / "ข้อสังเกตคือ…" / "จุดที่น่าสนใจกว่าตัวเลขคือ…" / "สิ่งที่ตลาดมักมองข้ามคือ…"
- ห้ามใช้: "ผม…" "ผมคิดว่า…" (เป็นเสียงทีม ไม่ใช่บุคคล)
- มุมมองบรรณาธิการแทรกได้ทั้งบทความ ไม่ใช่แค่ในกล่อง `>` ท้ายเรื่อง แต่ต้องแยกให้ชัดจากการรายงานข้อเท็จจริง

## 📊 Cross-asset — ต้องมีเสมอ

## 📐 คุณภาพงานเขียน
- **อธิบายศัพท์ครั้งแรกที่ใช้เสมอ** — Dot Plot, SEP, basis point, yen carry trade, yield curve ฯลฯ เขียนขยายความสั้น ๆ ในวงเล็บหรือประโยคถัดไป
- **ตัวเลขต้องมีบริบท** — ไม่ใช่ "ยีลด์ 10 ปีที่ 5.04%" แต่เป็น "ยีลด์ 10 ปีที่ 5.04% ซึ่งเป็นระดับสูงสุดนับตั้งแต่ปี 2007"
- **ความยาว** — โหมด A ราว 700–1,000 คำ / โหมด B ราว 1,200–1,800 คำ
- **หัวข้อต้องบอกสาระ** ไม่ใช่ป้ายกำกับ — ✅ "ทำไมเฟดถึงหันกลับมาคุมเข้ม" ❌ "ปัจจัยพื้นฐาน"
- ถ้าเขียนขณะตลาดยังไม่ปิด ต้องระบุชัดว่าตัวเลขเป็นสัญญาณจากตลาดล่วงหน้า/นอกเวลาทำการ
